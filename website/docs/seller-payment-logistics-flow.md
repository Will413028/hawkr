# Hawkr 金流與物流流程說明

> **從消費者下單，到賣家收款的完整交易流程**
>
> **現行版本：2026-08-13。** 本文件記載簽約後應採用的營運與產品基準；尚未完成的後端分帳、發票及折讓功能，仍須依 `docs/legal/hawkr-seller-platform-service-agreement-v1.2-verification.md` 驗收，不得把未實作狀態當成另一套商務規則。
>
> **費率基準已改為三方案版本化**：Starter 月費 NT$0＋成交服務費 6%、Growth 月費 NT$990＋3%、Pro 月費 NT$2,990＋0%。本文以 6% 舉例者，僅為 Starter 方案的情形；實際費率依該筆訂單鎖定的方案版本，見契約附件一方案表。

Hawkr 提供訂單系統、金流付款、物流串接、物流追蹤、發票狀態及對帳工具；池上多力米則負責商品資料、庫存、備貨、包裝、交寄、向消費者開立商品與買家支付運費的發票，以及商品售後。

---

## 一、完整交易流程

### 1｜消費者下單

消費者於 Hawkr 選擇池上多力米商品，確認商品規格、數量、配送方式、收件資料及付款方式後送出訂單。

**Hawkr 提供**

- 購物車與結帳系統
- 配送方式與運費計算
- 訂單成立通知
- 優惠券及折扣計算
- 收件資料與發票資訊欄位

**池上多力米負責**

- 商品資訊、價格與庫存正確
- 配送方式及出貨條件設定
- 商品效期、規格及標示完整

---

### 2｜金流付款

消費者透過 Hawkr 串接之第三方支付服務完成付款。付款成功後，系統將訂單更新為可備貨狀態。

可使用之付款方式依平台實際開放功能為準，例如：

- 信用卡
- Apple Pay
- ATM 虛擬帳號
- 超商代碼
- 其他平台公告之付款方式

**Hawkr 提供**

- 第三方支付系統串接
- 付款成功、失敗及逾時狀態同步
- 退款及金流異常處理介面
- 交易紀錄及對帳資料

**池上多力米負責**

- 完成第三方支付帳戶申請及身分審核
- 提供正確公司、銀行與稅務資料
- 不得要求消費者私下轉帳或繞過平台付款

> 消費者付款金額由第三方支付服務依約代收，並非由池上多力米於訂單成立時直接取得。

---

### 3｜訂單確認與備貨

付款成功後，池上多力米將於賣家後台收到新訂單通知，並依系統顯示之期限完成備貨。

**賣家應確認**

- 商品品項及數量
- 商品批次、效期及外觀品質
- 收件地址及配送溫層
- 包裝材積與物流規範
- 預計交寄時間

如發現缺貨、錯價、商品異常或無法如期出貨，池上多力米應立即透過平台流程回報，不得以虛假物流單號或空包裹延後訂單。

---

### 4｜物流單建立與商品交寄

池上多力米於後台選擇適用之物流服務，取得物流單號、寄件標籤或交寄資訊後，自行完成包裝及交寄。

配送方式依平台實際開放功能與商品條件為準，例如：

- 常溫宅配
- 冷藏宅配
- 冷凍宅配
- 超商取貨
- 都會即時配送
- 其他平台合作物流

**Hawkr 提供**

- 物流服務系統串接
- 運費及配送條件顯示
- 物流單號與寄件標籤
- 訂單配送狀態同步
- 買家物流查詢功能

**池上多力米負責**

- 正確選擇物流溫層
- 依物流規範完成包裝
- 確認材積、重量及標示
- 於期限內交寄商品
- 保留交寄及出貨相關紀錄

> 因賣家錯選溫層、超材、超重、包裝不當或延遲交寄所產生之追加運費、退件費及商品損失，由賣家負擔。

---

### 5｜配送追蹤與買家收貨

商品交寄後，物流業者將配送進度回傳至 Hawkr，消費者可於訂單頁查詢配送狀態。

常見物流狀態包括：

```
已建立物流單 → 賣家已交寄 → 物流配送中 → 配送完成 → 買家確認收貨 → 訂單完成
```

如發生配送延遲、地址錯誤、商品遺失、超商未取或拒收，平台將依物流紀錄及責任歸屬協助分流處理。

---

### 6｜發票開立

**消費者端商品及運費發票**

池上多力米是商品及買家支付運費的發票銷售人，應依自身稅籍、發票制度及適用法規，按實際交易內容與金額向消費者開立全額發票，並負責：

- 商品及買家支付運費的發票開立
- 發票作廢
- 退款折讓
- 發票更正
- 稅務申報
- 買受人統編及載具資料處理

**另外兩層發票**

統一合作法人依其與池上多力米間的上游合作契約及結算資料，開立相應發票給池上多力米；實際法人以該契約所載資料為準。Hawkr 則按月或依合作契約約定的結算週期，向統一合作法人辦理對帳、請款及開票。三者是不同契約與對價的獨立開票關係，費用由誰負擔不會改變發票買受人。

雙方應於正式上線前確認：

- 統一合作法人的完整名稱、統一編號及上游合作契約版本
- 三層發票各自的開立時點、品項、金額與適用稅別
- 買受人統編及載具處理
- 取消訂單之作廢方式
- 部分退款之折讓方式
- 運費退款與各層發票異常處理

---

### 7｜訂單完成與款項結算

商品完成配送，且售後申請期間屆滿、無退款或交易爭議後，訂單進入可結算狀態。

平台依約定週期提供以下對帳資料：

- 商品成交金額
- 賣家優惠券及折扣
- 平台優惠補貼
- 取消及退款金額
- 適用方案代碼與方案版本
- 方案月費
- 成交服務費（依訂單鎖定費率 6%／3%／0%）
- 金流手續費
- 物流相關費用
- 售後扣抵金額
- 最終應撥款金額

**賣家應收款計算方式**

```
  商品實際成交金額（已扣賣家折扣、取消、退款及折讓）
− 成交服務費（訂單鎖定費率 × 商品實際成交金額；Starter 6%／Growth 3%／Pro 0%，含稅）
− 該期方案月費（Starter NT$0／Growth NT$990／Pro NT$2,990，含稅）
− 金流手續費
− 人工服務費（如有另行選購）
+ 買家支付之運費
+ Hawkr 活動補貼
− 賣家應負擔之退款、物流或售後費用
━━━━━━━━━━━━━━━━━━━━━━
= 賣家應撥款金額
```

> 成交服務費是 Hawkr 完整的平台交易服務對價，費率依該筆訂單鎖定的方案版本（6%／3%／0%）計算；方案月費另按計費週期收取。PAYUNi、金融機構或付款工具的金流手續費由賣家另行負擔。買家支付的運費與 Hawkr 活動補貼不列入成交服務費計算基礎。

## 二、正常訂單金物流流程圖

```
消費者下單
  ↓
第三方支付完成付款
  ↓
Hawkr 建立訂單並通知賣家
  ↓
池上多力米備貨、包裝及交寄
  ↓
物流業者配送並回傳物流狀態
  ↓
消費者完成收貨
  ↓
售後期間屆滿且無爭議
  ↓
平台產生對帳明細
  ↓
第三方支付依約撥款予賣家
```

## 三、退款與售後流程

如訂單發生取消、商品瑕疵、缺件、錯寄、物流異常或品質爭議，依下列流程處理：

```
買家提出售後申請
  ↓
系統暫停該筆訂單撥款
  ↓
買家與賣家提交照片、物流及商品證據
  ↓
平台依交易紀錄與平台規則協助判斷
  ↓
執行退款、退貨、補寄、換貨或其他方案
  ↓
各層原發票開立人依實際退款結果分別辦理作廢、折讓或更正
  ↓
自賣家待撥款或後續款項中扣抵應負擔費用
  ↓
案件完成後恢復剩餘款項結算
```

> 平台提供售後案件系統、證據留存及爭議協調工具，但不取代池上多力米對商品品質、標示、包裝、出貨及依法應負之售後責任。

## 四、金物流責任分界

| 流程項目 | Hawkr | 池上多力米 |
| --- | --- | --- |
| 商品資料 | 提供上架系統 | 自行設定並確保正確 |
| 消費者付款 | 串接第三方支付 | 配合完成支付帳戶審核 |
| 訂單通知 | 系統自動通知 | 即時查看並處理 |
| 商品備貨 | 提供訂單資料 | 自行備貨與品質確認 |
| 商品包裝 | 提供物流規格說明 | 自行完成合規包裝 |
| 物流交寄 | 提供物流單及狀態串接 | 自行交付物流業者 |
| 消費者端商品及運費發票 | 提供必要狀態串接 | 自行依法開立、異動及申報 |
| 統一對賣家發票 | 依合作契約串接或記錄狀態 | 核對統一合作法人所開發票及配合異動 |
| Hawkr 對統一發票 | 依約定週期對帳、請款及開票 | 核對與自身結算相關的資料 |
| 配送追蹤 | 顯示物流狀態 | 配合處理出貨異常 |
| 商品售後 | 提供案件及證據系統 | 負責商品責任與處理 |
| 訂單對帳 | 提供費用與撥款明細 | 查閱並於期限內提出異議 |
| 款項撥付 | 依約串接及提供明細 | 提供正確收款帳戶 |

## 五、重要提醒

- 賣家不得要求消費者私下匯款或將訂單轉移至平台外成交。
- 賣家應確保後台庫存與實際可出貨數量一致。
- 商品交寄前，賣家應自行完成品質、效期、數量與包裝檢查。
- 消費者端商品及買家支付運費的發票與稅務責任，由池上多力米負責。
- 統一合作法人開給池上多力米、Hawkr 開給統一合作法人的發票，分別依各自合作契約與結算資料辦理。
- 發生退款、拒付、食安、物流或售後爭議時，平台得暫緩合理範圍內之待撥款項。
- 具體付款方式、物流服務、費率、撥款週期及發票流程，以正式合約、平台公告及第三方服務商當期規範為準。
