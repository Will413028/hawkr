## 1. gRPC server：`CouponService`（`J/grpc/CouponGrpcService.java`，proto 在 `P:11-42`）

所有 handler 的共同行為（逐一讀過）：業務失敗一律用 envelope（`code`／`message`，grpc 狀態是 OK）回傳（`onBusinessError`，`CouponGrpcService.java:1319`；賣家／admin handler 直接 `onNext` 帶 `e.code()`）；其他例外交給 `GrpcErrorHandler.handleException`（`:1334`）。買家 3 支與賣家 5 支、admin 8 支先 `GrpcAuthContext.requireAccountType(...)`；order 內部 4 支與 `GrantSellerCompensationCoupon` 不檢查角色（註解寫「由 x-internal-service 自動識別」，`:1059`），**handler 內沒有任何驗證**，驗證在 gRPC interceptor（shared 元件，本次未讀）【推】。時間欄位以 ISO 8601 字串進出，`LocalDateTime` 以 UTC 處理（`DateTimeUtils.nowUtc()`）。
