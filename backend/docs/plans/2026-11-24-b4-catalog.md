## 前提（核對日 2026-11-24，dev `496b048e2`）

- **會改到或取代的部署是否在線**：不在線。系統從未上線，不受回滾窗口、資料搬移、雙跑的約束；舊資料不搬（主計畫全域約束）。
- **cart、order 仍在 Java**（B6、B8）：cart 2 支、order 3 支 product RPC 在用（`client-inventory.md` §5【量】）；order 另以 MQ 發 `order.cancelled`（歸還庫存）與 `order.sales.accumulated`（銷量）給 product（`interface-inventory.md` §2【量】）→ D1。
- **ai-service 呼叫 product 4 支 RPC**（ProductService 3 支 `GetProduct`、`GetProductList`、`GetStock`，`backend/services/ai-service/internal/client/product/adapter.go`；CategoryService 1 支 `GetCategoryTree`，`client/category/adapter.go`【量】）；ai-service 由 A9 搬進單體並刪除（`2026-11-19-a9-agent.md`）→ D12。
- **單體已有 4 支 product RPC 的消費者**：seller（`ProductStores`）、social（`ProductVerifier`）、discovery（`StoresWithPublicProducts`）、buyer（收藏卡片）、procurement（搜尋、分類樹）經 `internal/legacy/productservice`、`categoryservice`（`interface-inventory.md` §9【量】）。B4 改接 catalog 模組。
- **事件**：buyer 收藏事件、review 的 `review.created`／`review.hidden`、order 的 `order.cancelled`／`order.sales.accumulated` 流入 product；product 發 `product.restock` 給 buyer（`interface-inventory.md` §2、§3【量】）。
- **B4 可與 B2、B7 並行**：B2、B7 計畫不依賴 catalog（`rg -n -i "product|catalog" 2026-11-23-b2-payment.md 2026-11-23-b7-coupon.md` 只命中 Stripe description 的預設【量】）。與 B3 的交界已對齊（2026-11-24）：D10 catalog 不存配送資訊；D11 `shipping_ambient.go` 由 B4 整檔刪，B3 只拿掉引用。
- **依賴表**：`catalog → {seller, buyer, media}`。現況 `modules.go:22` 還有 fulfillment【量】，B3 步驟 4 刪除（不建 fulfillment 模組，ADR `2026-11-15-fulfillment-seller-managed-shipping` 2026-11-24 修訂）；B4 若先動 `modules.go` 就一併刪，後合進 dev 的一方 rebase。
- **工具鏈**（預設，可推翻）：照根目錄 `AGENTS.md`。

**驗收基線：** B4-0 跑單體與 gateway 的 unit、`make lint-monolith`、Java product-service 的 `mvn test`，記在文末「基線」。dev 既有的紅照 B7 計畫進度表所列（`TestEveryServiceInTheContractIsMounted`、notification integration、pnpm lockfile）不在本階段修。integration 與 e2e 不在本機跑；CI 一次推一批。

## 本階段依賴的不變量

| 不變量 | 依賴它的機制 |
|---|---|
| 模組只 import 依賴表允許的根套件；buyer、seller 在 catalog 下層，review、cart、ordering、delegation 在上層 | `internal/arch/modules.go`；catalog 對 buyer 收藏事件的訂閱；review→catalog 的 `SetRating` |
| 暫時轉接只在 `internal/legacy/`，模組不 import | `legacy/catalogserver`（D1）；`legacy/productservice`、`categoryservice` 刪除 |
| SQL 只碰自己的 schema；跨模組讀用 API 或 `pub_*` | `modules/catalog/db/`；列表 join `seller.pub_exposable_stores(at)` |
| 同一冪等鍵的扣庫存只生效一次；歸還不超過原扣減 | `catalog.stock_movements`；`catalogserver` 的扣／還；B8 結帳（D2） |
| 庫存不為負 | 扣減的條件 UPDATE、CHECK `qty >= 0` |
| 衍生計數由事實擁有者在同 transaction 更新 | buyer 收藏、review 評分、銷量（D3） |
| 店家可曝光由 `seller.pub_exposable_stores(at)` 判定，時間用請求的 clock | 公開列表、搜尋、商品頁；`ListPublicStores` |
| 店家身分由呼叫者推導，不收 client 的 `store_id` | 賣家 Connect API（D4，CD9） |
| content 經 catalog 公開 API 確認 banner 的商品（依賴表加 content→catalog，ADR `2026-09-24-go-modular-monolith` D2 表同步） | `internal/arch/modules.go` 的 content 列；content 的 banner 商品動作 |
| 舊服務處理流量到 B4-6：訂閱、job、轉接只在測試接線，切換的同一變更才接到 `cmd/hawkr` | catalog 的事件訂閱、`catalogserver` 註冊點 |
