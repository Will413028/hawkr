# 運費計算模組（Shipping Fee Module）detailed-design

> **文件定位**：賣家運費設定與報價的現行規格（B3，seller 模組）。決策依據 ADR `docs/adr/2026-11-15-fulfillment-seller-managed-shipping.md` 的 2026-11-24 修訂：運費只用賣家自訂的固定規則，不做即時報價、不分區域與溫層。
>
> **取代的舊設計**：Java shipping 的 DB 費率表（`shipping_fee_tiers`）、`ShippingFeeCacheClient` 的快取、區域路線與材積重量計算隨 Java shipping 刪除；舊內容見 git 歷史。
>
> **範圍**：本書只記 B3 已決定的部分。表與 RPC 的欄位名稱以 `backend/docs/modules/seller.md` 與 `api/hawkr/seller/v1alpha1/seller.proto` 為準；結帳如何呼叫報價、如何快照進訂單由 B8 ordering 決定，不在這裡預先設計。

---

## 1. 運費設定（每個賣家一份）

| 項目 | 規則 |
|---|---|
| 固定運費 | 新台幣元，整數，非負；0 表示一律免運費 |
| 免運門檻 | 新台幣元，可以沒有（沒有表示不提供門檻免運） |
| 處理天數 | 1–7 個工作日，預設 3；逾期未出貨取消的期限由它決定（取消歸 B8 ordering） |

- 設定歸 seller 模組，只有一個擁有者；catalog 不存運費或配送方式。
- 設定的寫入只能寫自己的店；以資料庫約束（非負、處理天數範圍）擋掉不合法的值。
- 賣家上手清單的「運費設定」能力：建好運費設定才算完成（B3 R6）。

## 2. 報價（純函式）

- 輸入賣家的運費設定與商品小計，回傳運費與距免運門檻的差額。
- 運費規則：小計達到免運門檻時運費為 0，否則為固定運費；門檻沒有設定時一律收固定運費。
- 沒有 I/O、不讀時間、不讀其他模組；購物車預覽（B6）與結帳（B8）共用同一個函式，以 seller 根套件的函式 in-process 提供，不開對外 RPC。
- 結帳把報價結果快照進訂單，之後修改設定不回溯既有訂單。

## 3. 刻意不做的事

- 不做即時報價、不分區域、不分溫層、不依材積或重量計費。
- 不做平台補貼或平台負擔運費：免運由賣家的門檻決定，成本歸賣家。
- 不留運費費率的快取或 warm-up：設定是一列資料，沒有需要快取的呼叫鏈。
