## 金流服務費用

|------|---------|

| 國外卡 | 3.5% |
| 銀聯卡 | 2.8% |
| 分期付款(3期) | 2.9% |
| 分期付款(6期) | 3.5% |
| 分期付款(9期) | 4.0% |

|------|---------|

|------|---------|

### 電子錢包

| 收款通路 | 費用 (含稅) |
|------|---------|
| icash Pay | 2.5% |
| LINE Pay | 交易處理費0.2% (於交易完成後隔日收取) |
| 街口支付 | 2.5% (部分高風險產業將無法使用或適用不同費率) |

### 先買後付

| 收款通路 | 費用 (含稅) |
|------|---------|
| AFTEE | 2.5% (部分高風險產業將無法使用或適用不同費率) |

- 全平台服務手續費以單筆計收，四捨五入後不足一元以一元計。
- AFTEE交易於請款後若產生退款，將不返還交易手續費。

### 轉帳退款

賣方使用 PAYUNi 服務的收款方式：超商代碼、ATM轉帳時，若賣方有退款需求，可於會員後台自行發動轉帳退款，而退款手續費將依下表收取。

| 收款方式 | 退款費用 (含稅) |
|------|---------|
| 超商代碼 | 10元 |
| ATM轉帳 | 10元 |

- 轉帳退款費用以單筆計收。
- 信用卡退款需刷退處理，不提供轉帳退款。

## 物流服務費用

賣方使用 PAYUNi 服務的物流服務：超商取貨時，相關寄件代收包裹手續費如下。

### 7-ELEVEN 大宗寄倉B2C - 常溫

| 收款方式 | 費用 (含稅) |
|------|---------|
| 常溫寄件費 | 50元 / 件 |
| 取貨付款代收費 | 0.5% / 筆，四捨五入後不足1元以1元計算 |
| 退貨便寄件費 | 50元 / 件 |

- 進貨時間：週一至週六 08:00至14:00。
- 進貨地址：新北市樹林區佳園路二段70-1號 大智通文化行銷電子商務組收。
- 交寄費用：
  (1) 常溫寄件費：進驗成功D+1天時以「常溫50元/件」由商店UNi帳戶中扣除。
  (2) 退貨便寄件費：門市已收件D+1天時以「50元/件」由商店UNi帳戶中扣除。
- 代收費用：0.5%/筆，四捨五入後不足1元以1元計算。代收款將於已完成包裹成功取貨D+7天時，扣除手續費後入商店UNi帳戶。
- 出貨期限：於出貨日期14天內配達統大智通流中心。

### 7-ELEVEN 大宗寄倉B2C - 冷凍

| 收款方式 | 費用 (含稅) |
|------|---------|
| 冷凍寄件費 | 125元 / 件 |
| 取貨付款代收費 | 0.5% / 筆，四捨五入後不足1元以1元計算 |
| 冷凍上收費 | 1~29件，一件150元；30件以上，一件50元 |
| 冷凍廠退費 | 150元 / 件 |

- 送件方式：分為到府上收、自行寄貨。
- 到府上收：申請上收包裹一次只能提供一個取貨點，1~29件，一件150元；30件以上，一件50元(冷凍寄件費125元另計)。
- 自行寄件至物流中心須以3.5T以上型式的貨車運送物品。禁止使用自用客、轎車及步行進入廠區送貨，警衛室也不提供收貨服務，不符合的運送車輛及送貨方式物流中心將一律拒收。
- 交寄費用：
  (1) 冷凍寄件費：進驗成功/超才/商品捆包/溫度不合格D+1天時，以「冷凍125元/件」由商店UNi帳戶中扣除。
  (2) 冷凍上收費：物流驗收D+1天時，不論進驗結果成功或失敗都將以上表規則計算費用，將冷凍上收費用單日總額自商店UNi帳戶中扣除。
  (3) 冷凍廠退費：包裹因進驗失敗或買家未取而退回商店，收到退件貨態(廠退)D+1天時以「150元/件」由商店UNi帳戶中扣除。
- ※ 冷凍上收費僅針對大宗寄倉-冷凍寄件方式為到府上收的商店收取。所有商店開通大宗寄倉-冷凍服務時均設定寄件方式為「到府上收」，如要調整寄件方式為「自行寄貨」， 請來信(service@example.com)申請
- ※ 冷凍廠退費僅針對大宗寄倉-冷凍退貨方式設定為 「統昶物流中心配合貨運」的商店收取。
- 代收費用：0.5%/筆，四捨五入後不足1元以1元計算。代收款將於已完成包裹成功取貨D+7天時，扣除手續費後入商店UNi帳戶。
- 出貨期限：於出貨日期5天內配達統昶物流中心。

| 收款方式 | 撥款至 UNi帳戶時點 |

| 超商代碼 | 付款日+7日 |

| 先買後付 | 付款日+7日 |
| 超商取貨付款 | 成功取貨日+7日 |

|------|---------|
